NES 2.0 Mapper 397

NES 2.0 Mapper 295 is used for a single multicart from J.Y. Company:

1996 Soccer 6-in-1 (JY-082)

The same bits in register $D003 select both PRG and CHR outer banks. It is almost identical to NES 2.0 Mapper 295, except that PRG A17 selected via $8000-$8FFF is not masked off.

Outer Bank Register ($D003)

Mask: $F003

7654 3210
---- ----
.... .BBC
      +++- Select 128 KiB outer CHR-ROM bank (CHR A19..17)
      ++-- Select 256 KiB outer PRG-ROM bank (PRG A19..18)

PRG ($8000-$8FFF) and CHR ($9000-$AFFF) bank select register bits that select 256/128 KiB banks are masked off.

For a description of all other registers, see J.Y. Company ASIC.

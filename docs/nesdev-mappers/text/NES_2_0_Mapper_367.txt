NES 2.0 Mapper 367

NES 2.0 Mapper 367 denotes a 7-in-1 multicart using an unknown PCB ID that constitutes a variant of INES Mapper 205. It latches the address bits A0 and A1 instead of the data bits D0 and D1 when address range $6000-$7FFF is written to, and is otherwise identical to mapper 205.

Categories: Mappers with scanline IRQs, MMC3-like mappers, Multicart mappers
